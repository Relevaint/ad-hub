# Core skills

Platform-neutral. One folder per skill. `start-here` and `audience-research` are built
(2026-10-19); the rest are briefs in `BUILD-PLAN.md` and their names are placeholders.

| Skill | Job | Reaches live accounts |
|---|---|---|
| `start-here` (built) | Unclear requests; adding a business or an offer; what blocks going live | No |
| `audience-research` (built) | Who buys, in their own words, from sources read; ranked customer types | No |
| `competitor-ads` | What others are running | No |
| `ad-strategy` | Gaps, angles, plays, what to test next | No |
| `ad-creative` | Copy and finished ads; policy and claims check | No |
| `ad-setup` | Account, tracking, result signal, structure | Prepares only |
| `ad-launch` | Putting approved ads live | Yes |
| `ad-manage` | Monitor, pause, replace, budget | Yes |
| `ad-review` | Results in, learnings out | No (read-only) |

`ad-strategy/references/plays.md` already exists: the first plays library.
